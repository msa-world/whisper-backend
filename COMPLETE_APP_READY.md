## 🆘 QUICK TROUBLESHOOTING

### Issue: Microphone not working
**Solution:** 
1. Check browser microphone permission
2. Try refreshing the page
3. Check another app isn't using mic
4. Try different browser

### Issue: No voice response
**Solution:**
1. Check system volume not muted
2. Check browser audio isn't muted
3. Try refreshing page
4. Check speakers/headphones

### Issue: Weather not loading
**Solution:**
1. Check internet connection
2. Try different location name
3. Wait a few seconds
4. Try the demo button instead

### Issue: Speech recognition failing
**Solution:**
1. Speak more clearly
2. Reduce background noise
3. Check microphone works in other apps
4. Try typing instead
