## 🔧 TROUBLESHOOTING

### "No Greeting Voice Heard"
**Solution:**
1. Check speakers/headphones volume
2. Click somewhere on the page first
3. Reload the page (Ctrl+R or Cmd+R)
4. Try a different browser (Chrome is best)

### "Microphone Not Working"
**Solution:**
1. Allow microphone permission when browser asks
2. Try the "Speak" button again
3. Check browser microphone settings
4. Try Chrome or Edge (best support)

### "No Text-to-Speech Response"
**Solution:**
1. Check volume is on
2. Try typing instead of speaking
3. Reload the page
4. Try another browser

### "Connection Issues"
**Solution:**
- This app is STANDALONE - no internet needed for core features
- Only weather API needs internet (free)
- Make sure internet is working
